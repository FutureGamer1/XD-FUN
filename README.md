# 🕹️ XD-FUN: GAMER+ ENGINE v1.0

Welcome to **GAMER+ ENGINE**, an awesome text-based adventure game built completely in Python! 🚀

## 🎮 How to Play
1. Copy the code from `Main.py`.
2. Run it in any Python 3 app (like Pydroid 3).
3. Type in your player name and start exploring your digital world!

## 💰 Game Features
* **Gamer Phone Interface:** Access a built-in virtual phone.
* **Wallet System:** Start your adventure with 100 gamer coins.
* **Item Tracking:** Save up to purchase an epic gaming chair or a big TV!
